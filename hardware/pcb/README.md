**Datos de la placa:** 2 capas, ~150 × 150 mm, fabricada en JLCPCB.

## Cómo regenerarlo

- Desde Altium: OutJob → **Documentation Outputs → PCB Prints**, salida a PDF.
- Para un dibujo de armado: **Assembly Outputs → Assembly Drawings**.
