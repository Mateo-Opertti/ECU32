**Pautas:**

- PNG para renders y capturas; JPG para fotos.
- Que cada imagen pese **menos de 1 MB**, porque GitHub guarda cada versión para siempre. Achicá las fotos a ~1600 px de ancho.
- Nombres en minúsculas, con guiones y sin espacios.
