# Firmware

Proyecto de STM32CubeIDE para el STM32G491VCT6.

Guardá acá el proyecto completo: `.ioc`, `Core/`, `Drivers/`, `.project`, `.cproject` y el script del linker. Las carpetas de build (`Debug/`, `Release/`) quedan excluidas por el `.gitignore`.

Las notas de arranque (orden de habilitación de /OE, STB de CAN, EN de LIN, etc.) están en el [README principal](../README.md#firmware-notas-de-arranque).
